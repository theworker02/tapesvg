# tapesvg

Tape HTML/Markdown svg fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/tapesvg/

## Install / run

```bash
git clone https://github.com/theworker02/tapesvg.git
cd tapesvg
node src/cli.js
node --test
```
